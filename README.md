# zmeter-firmware


## Prerequisites

To build this project, you need to have the ESP-IDF environment set up(version 6.0.x is currently used).

## Building the Project

To build the project, navigate to the project root directory and run:

```bash
idf.py build
```

## Flashing and Monitoring


To flash the firmware to your device and open the serial monitor:

```bash
idf.py flash monitor
```
